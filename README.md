# – Protótipo Inicial do Site

Esta branch contém o **protótipo inicial** do site, desenvolvido como base estrutural e visual do projeto.  
Cada pasta representa uma **página ou módulo** independente, com seus próprios arquivos HTML, CSS e JavaScript.

Antes de haver a branch "projetotcc" nós utilizavamos esta branch inicialmente, aqui nós tivemos a prática de toda nossa ideia, e com o decorrer dos meses 
fomos aprendendo mais e obtendo mais dicas para adicionarmos ao nosso projeto
---

## ⚙️ Como Usar no VS Code

1. **Abrir o projeto**
   - Abra o **Visual Studio Code (VS Code)**.
   - Vá em **File → Open Folder** e selecione a pasta raiz do projeto.

2. **Instalar o servidor local**
   - Instale a extensão **“Live Server”** (desenvolvida por Ritwick Dey).
   - Após instalar, abra qualquer arquivo `index.html`.
   - Clique em **“Go Live”** no canto inferior direito do VS Code.

3. **Visualizar o site**
   - O navegador abrirá automaticamente exibindo o site localmente, por exemplo:
     ```
     http://127.0.0.1:5500/pagina_inicial/index.html
     ```

4. **Editar e testar**
   - Faça alterações nos arquivos `.html`, `.css` e `.js` de cada página.
   - O **Live Server** atualiza automaticamente as mudanças no navegador.

## 🧩 Organização e Padrões

- **HTML** → Estrutura de cada página  
- **CSS** → Estilos visuais organizados por página  
- **JS** → Scripts de interatividade e animações  
- **assets_geral/** → Recursos compartilhados por todo o projeto  
- **bootstraps/** → Componentes reutilizáveis (header, footer, scripts comuns)

## 🚀 Sobre esta Branch

> 🔹 Esta branch, por ser o **protótipo inicial** do projeto.

Ela define:
- A ideia do projeto fora do papel;
- O layout base das páginas;
- Os componentes reutilizáveis (header, footer e scripts globais);
- A base para futuras melhorias de design e funcionalidades.

Próximas versões incluirão:
- Integração com banco de dados;
- Backend (PHP ou Node.js);
- Sistema de login funcional;
- Layout aprimorado e responsivo.
- Página de pagamento
